#Finova
It's is a responsive and user-friendly web application designed to help users efficiently manage their personal finances. It allows users to record income and expenses, categorize transactions, monitor their total balance, and view their spending patterns through a clean and modern dashboard.

# FINOVA

> Personal finance, simplified.

A modern and responsive expense tracking dashboard built with
**HTML, CSS and JavaScript**.
---
## FEATURES

- Income and expense tracking
- Real-time balance calculation
- Category-based spending analysis
- Transaction search and filtering
- LocalStorage persistence
- Responsive interface
- Dark mode

## STACK

`HTML5` `CSS3` `JavaScript` `LocalStorage`
